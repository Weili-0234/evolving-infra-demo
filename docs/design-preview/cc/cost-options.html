这些定义分别回答什么

A 看处理 token 的平均单价；B 看生成一定量输出的总账单；C 看一次模型调用平均花多少钱。B 包含输入费用，不是单独的 output-token 标价。

所有选项都从同一批已完成调用累计计算，CUA 与 CC 的窗口长度分别标注。Provider revenue 是累计计价金额；User cost 是平均值。

“每个完成的 agent session 花费”需要匹配同一批 session；不能直接拿整小时 revenue 除以完成 session 数，因为 revenue 也包含未完成 session 已产生的调用费用。
