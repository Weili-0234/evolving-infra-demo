Data, playback, and pricing

The first scene replays matched session fd0aecb95d7f. Both arms have 25 model calls, 15,028 output tokens, and matching per-call prompt and output lengths. Cache hit and user cost accumulate over completed calls only. Cache hit is cached input tokens divided by all input tokens. Cost per million tokens is cumulative charge divided by cumulative input plus output tokens, multiplied by one million; cached input is counted once. Before the first completion both values are undefined. The terminal status reports the current first-token wait.

Tool-call and between-request intervals have zero screen time. Recorded first-token waits and decode intervals are preserved on a model-serving timeline, including overlapping requests. Both panels use the same playback rate: 8× while either panel streams output, 120× during waits with no output. The model clock excludes the omitted intervals. Original session elapsed times are 31:03 for Dynamo and 10:51 for Evolving Infra.

Terminal text is illustrative. Tool commands, filenames, diffs and test results are illustrative too. The source events contain timing and token counts, but no transcript or individual token-arrival timestamps; text reveal is interpolated between first-token and completion events. The sample demonstrates cache reuse alongside measured latency; the runs also differ in allocation and routing, so this is not a cache-only causal ablation.

The second scene uses the original one-hour measurement window after a 30-minute warmup, including tool time, across all 126 concurrent agents on 36 GB300 GPUs per system. Curves are sampled every 10 seconds. Cumulative average cache hit is the sum of cached input tokens divided by the sum of input tokens for completed calls, not the mean of request percentages or a moving-window average.

User cost and revenue are valuations at the demo's token rates: $1.40 per million uncached input tokens, $0.26 per million cached input tokens, and $4.40 per million output tokens. Revenue sums these charges over completed calls; user cost per million tokens divides that sum by all input and output tokens, then multiplies by one million. They are not independently measured payments. The matched-session cost and the full-run average have different cohorts.

Full-hour totals: Dynamo — 7,710 calls, $459.72 revenue, 90.9% cache hit, $0.3952 per million input + output tokens. Evolving Infra — 21,302 calls, $1,082.77 revenue, 96.3% cache hit, $0.3312 per million input + output tokens.
